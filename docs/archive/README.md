# Archived audits

Dated audits, implementation plans and progress reports live here. They are
**historical evidence**, not current specifications: several describe
behaviour that has since changed, and one describes a response-presentation
selector the user deliberately removed on 21 October 2026.

Read the live documents in `docs/` for current behaviour:

- `docs/PERMISSIONS.md` — access modes and the rule-based permission layer
- `docs/TOOL_DISCOVERY.md` — how the tool catalog is assembled and deferred
- `docs/WORKSPACE.md` — workspace editing, transactions and formatting
- `docs/SKILLS.md` — skills and the model-facing skill tools
- `docs/RENDERING.md` — rendering primitives and the colour contract

These files are kept for provenance: they record what was decided, when, and
why. Nothing here is a task list.
