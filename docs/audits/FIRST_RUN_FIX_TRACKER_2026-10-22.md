## Release limits

The platform acceptance procedures in the setup guide remain mandatory before claiming a supported release across these systems. In particular, managed downloads still cover one verified Windows x64 CUDA package; other platforms/backends have native executable setup paths. Compatibility preflight rejects known errors but does not promise unknown model architectures will load. Storage migration retains original data and temporarily needs copy space. Filesystems lacking atomic hard-link publication require another volume. No commit or publication was requested or performed, and existing staged user work was preserved.
