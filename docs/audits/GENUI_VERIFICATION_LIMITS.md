# Verification boundaries

No browser, proxy preview or Playwright run was used. New browser fixtures are
source coverage only until the workspace restriction changes. Linux native tests
use a separate Xvfb/D-Bus session and isolated XDG data, never the user's database.
Selected model preferences are read-only input; actual model inference is opt-in
through the existing local benchmark/native command environment.

Generated UI cannot certify arbitrary prose. The new provenance gate rejects
ambiguous or unsupported rows/metrics/code/citations rather than guessing. Diagram
and educational semantics still require the authoritative answer and model output
to be correct; schema validation and a directed layout are not factual proof.

Node validation timings measure parsing/bounds, not UI paint. The bundle comparison
builds the same source/config with Markdown/literal-code substitutes at the three
visual entrypoints, and sums all JS/CSS. This is incremental total download size,
not initial download or lazy-loading latency. AT-SPI action-to-label times include
accessibility traversal and polling. Native process high-water RSS is reported per
process; it is not a simultaneous summed application working set.

The repeated CPU benchmark loads a separate local runtime once and rotates case
order, with cache_prompt explicitly enabled or disabled. It never flushes OS page
cache. Raw-content tokenizer counts exclude chat-template framing unless provider
usage counters are present. The fixed Python subprocess case is actual execution
but is not a model-selected permission-controlled tool call. Real harness boundaries
are exercised by the loopback plan/approval/write/final-answer/formatter integration
test; that mock is not model reliability evidence.

A first exploratory repeated run was interrupted after build/test contention was
observed. Its partial output remains under `.local/qa/genui-repeated-2026-10-21`;
it must not be combined with the later completed measurement run (background desktop/compiler activity was recorded) or reported as complete.

Remote/provider authentication, paid calls, GPU performance, Windows/macOS native
behavior and physical-device/screen-reader certification have not been verified.
Strict Clippy currently reports unrelated existing diagnostics across the repository.
No lint suppression, security reduction or fabricated placeholder modules are used
to claim those gates passed. See the completion tracker for actual final results.

The final native run pins a copied debug executable and recursively hashes a frozen
source snapshot. Another active session changed unrelated backend modules and
removed the composer selector during this task. The snapshot includes the final
generative UI changes with coherent surrounding backend; it cannot certify every
subsequent edit in the live working tree. The live Settings-only preference design
was preserved. Historical build-blocker removal is not permission to remove real
modules later supplied by that session.

The selected local model produced a correct host-bound chart in the real app and
restored it after restart. The separate real workspace-read scenario failed before
any tool result: the installed llama-server rejected the model's tool prompt with
HTTP 500, `NotImplemented: map: filter-mapping not implemented`. The harness timed
out waiting for a presentation and exited nonzero; its main report remains failed.
No native tool-assisted success or universal model reliability is claimed.

The first consolidated full Rust run reported 819 passes, two failures and 17
ignored tests. Both failures queried or spawned `current_exe()` after another Cargo
session replaced the shared target executable (`NotFound` and a failed existence
check). This run is retained in `/tmp/locallm-genui-delivery-rust.log`. The rerun
builds the same snapshot, immediately copies its library test executable outside
Cargo's target tree, and executes the complete suite from that immutable copy.
It does not omit or weaken either test.

The pinned complete library rerun passed: 821 tests, zero failures, 17 ignored.
The failed original command did not proceed to bin/doc suites; those are not
claimed as freshly passing. Live Rust library check and frontend typecheck passed.
Strict snapshot Clippy still fails (84 library / 102 test-library diagnostics).
